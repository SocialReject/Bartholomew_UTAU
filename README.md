# Bartholomew_UTAU
UTAU Beast English Vocalist Prototype for Country and Folk

This is a test voicebank of the beast country vocalist project Bartholomew
For a few years I've wanted to develop a singing synthesis voicebank that could theoretically be suitable for folk and country.
Recently I've started developing Bartholomew and created a prototype that can be used.

There is currently no license to this voicebank, it is for personal use only. I'm uploading this for hobbyists who would like a UTAU vocalist for less utilized genres.

Use the rendered vocals for use in Band in a Box or whatever music making software of your choice!
